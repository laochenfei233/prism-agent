# 自动归档

[English](auto-archive.md) | 中文

## Summary

自动归档是按计划进行的整理：把长期不用的对话和项目移出侧边栏，且不删除任何内容。捆绑插件 `prism-session-autoarchive` 每个间隔跑一趟扫描：最后写入时间早于对话窗口的顶层会话进入归档集；不再有可见会话、且安静超过项目窗口的项目进入项目归档集。两个集合与侧边栏自带归档动作写入的是同一份持久、可逆的状态，一切都可以恢复。

该功能**默认关闭**。在设置里打开插件的 `enabled` 开关（位于插件自动生成的设置页）；部署也可以在 `cordis.patch.yml` 行里写 `enabled: true`。以默认值启用时，会话闲置 30 天归档，项目安静 14 天归档。

<a id="what-the-sweep-touches"></a>
## 扫描处理什么

只有顶层对话会入选：已 pin 的会话、子代理会话和分叉会话一律跳过；回合仍在进行的会话会被归档集拒绝并跳过——自动整理绝不取消正在运行的工作。活动时钟取会话的最后一次写入，因此导入的对话按自己的日志计时。

项目（Workspace）在同一趟里评估。只有当它名下没有任何可见顶层会话、且最新写入——从未用过的项目取注册时间——早于 `projectIdleDays` 时才会隐藏。隐藏项目一旦重新出现可见会话（例如计划提醒投递了新会话进来），下一趟扫描会自动恢复它。

对话窗口为 7 天时，出厂的项目窗口 14 天读作 7+7：对话第 7 天归档，此时项目已无可见会话，再过 7 天项目归档。

<a id="projects-and-the-default-workspace"></a>
## 项目与默认工作区

默认工作区——应用首次使用时注册的第一个文件夹——豁免：除非部署设置 `includeDefaultWorkspace: true`，扫描绝不会隐藏它。其余项目按同一规则进入归档集。

<a id="restoring"></a>
## 恢复对话与项目

- **对话：**打开设置 → 已归档对话，逐个恢复，或使用侧边栏自带的归档控件。恢复后对话回到原项目。
- **项目：**打开设置 → 已归档项目，恢复对应行；项目带着标题、顺序和会话原样回来。通过正常流程重新添加同一文件夹也会恢复原注册——文件夹路径就是项目的身份，不会产生重复项目。

<a id="configuration-reference"></a>
## 配置参考

| 字段 | 默认 | 范围 | 作用 |
|---|---|---|---|
| `enabled` | `false` | boolean | 总开关；`false` 时插件保持挂载但不做任何扫描 |
| `idleDays` | `30` | 1–3650 | 会话多少天没有对话后进入归档集 |
| `projectIdleDays` | `14` | 1–3650 | 项目多少天没有任何会话写入后进入项目归档集 |
| `includeDefaultWorkspace` | `false` | boolean | 是否允许默认工作区在闲置后被归档 |
| `sweepIntervalMinutes` | `1440` | 5–10080 | 扫描间隔（分钟） |

每个字段都可以在插件自动生成的设置页里实时修改；修改在下一趟扫描生效，无需重启。
