# dsh-desktop — Prism Agent 桌面客户端

[English](README.md) | 中文

<!-- PRISM-DIVERGENCE: replay list in docs/compose/spec/fork-upstream-divergence.md (S2). -->

Tauri 2 桌面壳：在原生窗口里内嵌 dsh web UI，内置 Node 运行时与裁剪后的 dsh 发行，开箱即用、关窗不退出（托盘常驻）、服务崩溃自动重启。Prism 使用独立 bundle id（`ai.prism.agent.desktop`），因此 WebView2 与浏览器会话数据不会与 DeepSeek Harness Desktop 重叠。**不修改任何上游 `packages/` / `apps/cli` 代码**，四个 agent preset（`standard` / `code` / `minimal` / `cordis`）由上游原样提供。

## 架构

```
src-tauri/            Rust shell
  src/dsh_runner.rs   dsh child-process lifecycle: spawn `dsh web --port 3081 --no-open`, port health probe, crash auto-restart (does not race when dsh-plugin restarts itself)
  src/tray.rs         tray residency: closing the window hides it; only tray Quit ends the process tree
  src/setup.rs        first-launch profile seeding: preinstall the bundled default plugins into the web profile (patch + bundle layers)
ui/dist/              shell frontend (pure static, no build): index.html full-window iframe + error banner
scripts/bundle-runtime.mjs  pack Node runtime + pnpm-deployed dsh closure + local plugins → runtime/
runtime/              packaging output (not committed; generated by CI; tauri.conf.json maps it as bundle resources)
```

端口与认证约定：壳内 `dsh web` 默认监听 `127.0.0.1:3081`；该端口被外部进程占用时，壳自动向上扫描空闲端口（3082 起）并以 `--port` 传入。Rust 壳解析 `dsh web` 打印的带令牌启动 URL，通过 `dsh_status` 与 `dsh://launch-url` 提供给前端；前端先用该 URL 完成回环浏览器会话换取 Cookie，再进入干净的源。由于壳把界面嵌在跨站 iframe 中，桌面发行版的 Cookie 会改为 `SameSite=None; Secure`；API 仍由回环 Host/Origin 信任检查把关。CLI 用户的 `dsh web` 默认 3080 不受影响。`/api`（含 `host.openPath`、WebSocket 下行、SSE）全部由 dsh 自身提供，壳不做反向代理。壳不渲染顶部导航栏，界面完全由 dsh UI 自身提供；壳与 iframe 之间只走宿主桥（`source: 'dsh-desktop-host'`）：界面就绪回报、原生通知与外部链接。

启动呈现：窗口打开后由壳自带启动页覆盖等待。`scripts/bundle-runtime.mjs` 向被服务的页面注入宿主桥：桥先请求壳保持该启动页，再在客户端插件激活、应用接管挂载点后回报——该时刻晚于 iframe 的 load 事件。不含该桥的页面（用未打补丁 dist 播种的 dev 运行时）沿用 load 即撤下的行为；桥始终不上报时由壳的 20 秒兜底。

复用已有 hub：壳把自己启动的 hub 记录在 `$DSH_HOME/desktop-server.json`（端口、启动 URL、pid，以及 CLI 入口及其长度与修改时间）；下次启动时，只要记录中的入口正是本次构建的入口、且对该端口发出回环 `GET /?token=…` 仍能得到 303，壳就采纳这个 hub，而不再启动第二个。被采纳的 hub 会跳过 `ensure_home_node_modules`、`ensure_default_plugins`、端口选择、spawn 以及整个 `dsh web` 启动过程；`dsh_status`、`dsh://ready` 与前端的带鉴权加载与启动出的 hub 完全一致，"Restart service" 会先复核记录、再按 pid 结束被采纳的 hub，由 supervisor 替换它。只有记录所指的 hub 确实停止服务后才会丢弃记录，因此比壳活得更久的 hub 仍可被下次启动采纳。在采纳 hub 之前、以及每次冷启之前，壳会结束本产品自己的其他 hub——装机闭包或本 checkout 起的那些，绝不碰其他 harness 构建——让一个 home 只有一个写者；debug 构建跳过清场，因此开发壳不会结束装机版的 hub。

Web 权限：dsh UI 运行在 iframe 里的回环源上，因此壳只授予桌面客户端确实可用的那几项。`ui/dist/index.html` 把 `microphone`、`camera`、`display-capture`、`geolocation`、`notifications`、`autoplay`、`fullscreen`、`clipboard-read`、`clipboard-write` 委托给该 iframe——跨源 iframe 在 WebView2 被询问之前就会被拒；`src-tauri/src/lib.rs` 对 WebView2 的 `PermissionRequested` 在麦克风、摄像头、地理位置、通知、剪贴板读取、自动播放和文件读写上回答 `Allow`。宿主不回答的种类 WebView2 一律拒绝且不弹窗，这正是录音报 “Permission denied” 的原因；MIDI、传感器与窗口管理保持不回答。该 WebView2 SDK 没有屏幕捕获的权限种类，因此 `display-capture` 的策略委托就是全部授权。Tauri 侧向壳窗口开放 `core`、`opener`、`notification`、`dialog`、`fs`、`clipboard-manager` 的 default 权限。主窗口设置了 `dragDropEnabled: false`；否则平台 webview 会吞掉 HTML5 drop 事件，UI 自带的附件拖拽永远不会触发。文件与图片上传完全不需要壳的权限：UI 打开文件选择框并经 `/api` 上传。

## 开发

前置：Node ≥ 22.19、pnpm ≥ 11、Rust ≥ 1.77、Tauri CLI（随本包 devDependency 提供）。

```sh
pnpm install                # workspace dependencies
pnpm run build              # produce lib and apps/web/dist (static frontend for dsh web)
pnpm tauri dev              # from apps/desktop; dev mode uses PATH node + apps/cli/lib/bin.js
```

dev 模式需要已构建的 CLI 产物（`pnpm run build`）；也可用环境变量覆盖运行时解析：
`DSH_DESKTOP_NODE`（node 可执行）、`DSH_DESKTOP_DSH_BIN`（dsh CLI 入口）、`DSH_DESKTOP_PLUGINS_DIR`（本地插件目录）。

## 构建发行版

```sh
pnpm run build              # repository artifacts
node scripts/bundle-runtime.mjs --platform win   # win|mac|linux; generates runtime/
pnpm tauri build            # package installers (runtime/ is bundled as resources)
```

Windows NSIS 安装器仅安装到当前用户：目标是 `%LOCALAPPDATA%\Prism Agent`，不需要提权；根据系统语言自动选择英文、简体中文或繁体中文；在开始菜单创建 `Prism Agent` 快捷方式，并使用 `src-tauri/icons/` 中的品牌化安装器头图与侧栏图。

CI（`.github/workflows/desktop-release.yml`）在三平台矩阵上执行同一流程并上传 GitHub Release；打 `v*` tag 或手动触发。

## 首次启动

- 默认预设：`standard`（上游默认值；如需切换，在 `~/.prism/profiles/web/cordis.patch.yml` 中设置 `agent-presets.config.default`）
- 本地内置插件：`aegis`、`dsh-agent-progress`、`dsh-tauri`、`prism-guardrails`；`prism-meeting` 随实验性语音输入 bundle 一起提供，用于带语音转写的会议纪要；`dsh-plugin` 为插件中心/市场，`dsh-win-terminal-inspector` 为 Windows 终端检查器
- 可选插件（通过插件中心安装）：`dsh-better-sidebar`、`dsh-notification`、`dsh-session-context-menu`、`@xmanrui/dsh-im`（企微/飞书/钉钉/微信/QQ 等 9 渠道）、`dsh-lark`、`dsh-qqbot`、`dsh-vision-router`、`graph-memory`、`aegis`

插件安装/更新/卸载全部走 dsh 官方机制（`dsh plugin` / dsh-plugin 插件中心），运行时内置 pnpm 与其同版本族。
